# vim‑nvim‑config

My **hybrid** configuration for **Vim** and **Neovim**.  
- `.vimrc` → classic Vim (and Neovim fallback)  
- `init.lua` → modern Neovim setup

Both files are maintained together to provide a consistent editing experience across editors.
